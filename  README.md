# mssql2mysql

MSSQL to MySQL migration tool with support for:

- Data migration
- Primary key migration
- Foreign key migration
- Config-based execution

## Installation

pip install mssql2mysql

## Quick Start

mssql2mysql --init
mssql2mysql --config migration.yaml

## Features

- Batch data migration
- Progress tracking
- Strict and safe modes
- Automatic PK & FK handling

## Requirements

- Python 3.9+
- SQL Server ODBC Driver
- MySQL Server
